# digit-identifier

Small educational neural network for classifying MNIST handwritten digits (pure NumPy implementation).

## What’s in this repo
- `digit_classification.py` — the `Network` class and training/evaluation code.
- `data_loader.py` — helper that loads `mnist.pkl.gz` and wraps the data for training.
- `digit_gui.py` — GUI which allows testing of individual digits via direct user input(fun!!)
- `data/` (ignored) — place `mnist.pkl.gz` here (not checked into git).
